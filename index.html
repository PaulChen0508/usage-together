关于用量伴侣 · 2.0.2

GPT 数据来自本机已登录的 Codex / ChatGPT Work 账户，模型列表会自动更新，包括账户可用的 GPT-6.1 Sol。

这里展示的是账户返回的额度分组。多个模型可能共享同一份额度；普通 ChatGPT 对话和 OpenAI API 账单用量不在此范围内。

Claude 数据来自已登录的 Claude Code。首次读取钥匙串可能出现系统授权提示；登录过期时请重新登录，再点刷新。

剩余额度 = 100% − 已用额度。它是额度比例，无法换算成固定的聊天次数。没有数据时显示「—」，并保留旧数据的时间。

两边都每 5 分钟自动查询。Claude 的 /usage 接口未公开文档化，服务更新可能影响读取。程序只读用量，不发送聊天，不消耗重置券。

拖动窗口标题栏调整位置。× 隐藏窗口，菜单栏可以重新打开；菜单栏「退出」结束程序。
